# Portfolio — Kwaku Quartey Ansah Ofei

Source for my personal portfolio site, a single static page with no build step.

- `index.html` — content and structure
- `styles.css` — theme, layout, responsive design (light/dark)
- `script.js` — year stamp and theme toggle
- `CNAME` — custom domain for GitHub Pages (kwakuquarteyansah.com)
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Run locally

Open `index.html` in a browser, or serve it:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```
